**무엇**

- `next-sitemap.config.js` — `exclude: ['/en']` 제거, `additionalPaths` 로 `/contact` 4개 언어 추가

**왜** 기본 언어 신호가 세 방향으로 어긋나 있었습니다.

| 위치 | 이전 값 |
|---|---|
| 미들웨어 `fallbackLng` | `en` — 언어 미정 방문자를 `/en` 으로 |
| hreflang `x-default` | `/ko` |
| 사이트맵 `exclude` | `/en` 제외 |

방문자는 영어로 보내면서, 검색엔진에는 한국어가 기본이라 하고, 사이트맵에서는 영어 홈을 숨기는 상태였습니다. 국내 B2B 가 주력이므로 `ko` 로 통일했습니다.

`exclude: ['/en']` 은 정확히 일치하는 경로만 제외하므로 영어 홈만 빠지고 `/en/about` 등은 남아, 언어 하나만 홈이 없는 비대칭 상태를 만들었습니다.

`/contact` 는 `searchParams` 를 써서 동적 렌더링(빌드 출력 `ƒ`)으로 분류되어 next-sitemap 자동 수집에서 빠져 있었습니다. **B2B 에서 문의 페이지는 전환 페이지인데 색인 대상이 아니었습니다.**

설정 방법은 추측하지 않고 `node_modules/next-sitemap/dist/@types/interface.d.ts` 에서 `additionalPaths` 시그니처를 직접 확인했습니다.
