== 작업 2: 쇼룸 갤러리 이미지 지연 로딩 ==

파일: src/components/ShowroomGallery.tsx

현재 제품 그리드가 이렇게 되어 있다 (203줄 근처):

  {filteredProducts.map(p => (
    <div key={p.id} className="product-card" onClick={() => openDrawer(p)}>
      <div className="product-img-wrap">
        <img src={p.img} alt={...} onError={...} />

<img>에 loading 속성이 없어서 기본값 eager로 동작한다.
초기 필터가 'all'이라 68장이 전부 렌더되고, 평균 2.9MB PNG가
뷰포트 밖까지 포함해 마운트 즉시 동시 요청된다. 약 200MB다.
실제 표시 크기는 280x320px다.

수정 내용:
1) map 콜백에 인덱스를 추가한다:  filteredProducts.map((p, idx) => (
2) 그리드 <img>에 다음을 추가한다:
     loading={idx < 8 ? 'eager' : 'lazy'}
     decoding="async"
   (상단 8장만 즉시 로드, 나머지는 지연)
3) 드로어(상세) 안의 <img> (227줄 근처)에도
     loading="lazy" decoding="async"
   를 추가한다.

이번 작업에서는 next/image로 바꾸지 마라. 원본 이미지 정리가 선행돼야 해서
별도 작업으로 잡혀 있다. loading/decoding 속성만 추가해라.
JSX 구조나 className은 건드리지 마라.


== 작업 3: 번역 키 누락 시 페이지 백지 방어 ==

파일: src/components/ProcessSection.tsx

99줄 근처에 이런 코드가 있다:

  {step.checks.map((check: string, i: number) => (

바로 위 55줄에서 `if (!dict || !dict.steps) return null;` 로 steps만 검사하고
checks는 검사하지 않는다. en/ja/zh 사전 중 하나라도 checks 키가 없으면
Cannot read properties of undefined 로 클라이언트 렌더가 터져
/capabilities 페이지 전체가 백지가 된다. dict 타입이 any라 빌드도 못 잡는다.

수정 내용:
  (step.checks ?? []).map((check: string, i: number) => (

그리고 같은 파일에서 dict 하위 속성을 방어 없이 .map() 또는 .length 로
접근하는 곳이 더 있는지 확인하고, 있으면 같은 방식(?? [] 또는 ?? '')으로
방어해라. 없으면 없다고 보고해라. 임의로 다른 파일까지 손대지 마라.

## 검수 기준 — 결과를 받으면 이걸로 확인

### 반드시 확인할 것

| 항목 | 통과 조건 |
|---|---|
| 빌드 | `npm run build` 성공. 타입 에러 0 |
| 라우트 표시 | 정적(`○`)이던 라우트가 동적(`ƒ`)으로 바뀐 게 없어야 함. 바뀌었으면 원인을 물어볼 것 |
| 참조 검색 | 삭제한 10개 HTML이 `src/`에서 참조되지 않음을 확인한 출력이 있어야 함 |
| `robots.txt`·`sitemap.xml` | **삭제되지 않았는지 반드시 확인.** next-sitemap 생성물이라 지우면 SEO가 통째로 날아감 |
| diff 범위 | `ShowroomGallery.tsx`는 `loading`/`decoding` 속성과 `(p, idx)` 외에 변경 없어야 함 |

### 흔한 실패 패턴

- **"완료했습니다"만 오고 빌드 출력이 없음** → 다시 요구하세요. 이게 이 프로젝트에서 반복된 사고 지점입니다.
- **`public/robots.txt`를 같이 지움** — "public에 있는 잔재 파일 정리"로 확대 해석하는 경우가 있습니다. `.gitignore`에 들어 있어 git에는 안 보이지만 로컬에는 존재합니다.
- **`next/image`로 바꿔버림** — 시키지 않은 일입니다. 원본이 2.9MB PNG인 채로 `next/image`만 붙이면 최초 변환 비용이 서버에 그대로 걸립니다.
- **`ShowroomGallery.tsx`를 통째로 리팩터링** — 68행 데이터 배열을 `useMemo`로 빼거나 접근성을 고치는 것은 P2 작업입니다. 이번 커밋에 섞이면 문제 생겼을 때 원인 특정이 안 됩니다.
