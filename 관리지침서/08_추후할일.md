## 대기 중 — 외부에서 자료가 와야 함

### ⏳ 쇼룸 제품 설명

**현재 상태** 쇼룸 제품에는 **설명이 아예 없습니다.** 사진, 모델명(DAON-00), 품목명, 태그만 표시됩니다.

> **정정 (2026-08-27)** 이전에 "사전의 임시 문구 `[임시 특징 설명]...` 가 라이브에 나가고 있다"고 적었으나 사실이 아닙니다. 그 문구가 들어 있는 `dict.showroom.products` 배열은 어디서도 사용되지 않는 죽은 데이터이고, 화면은 `dict.showroom_ui` 만 씁니다. 고객에게 노출되지 않습니다.

**막고 있는 것** 업체 대표에게 제품 설명 자료를 요청해 둔 상태 (2026년 6월경 요청). 대표가 바빠서 지연 중.

**작업 성격** 자료가 오면 "임시 문구 교체"가 아니라 **설명 표시 기능을 새로 붙이는 작업**입니다.
1. `ShowroomGallery.tsx` 의 `rawData` 에 설명 필드 추가 (또는 사전에서 읽도록 변경)
2. 드로어(상세 창)에 설명 표시 영역 추가
3. 4개 언어 번역

**왜 중요한가** 쇼룸은 롱테일 검색이 가장 잘 걸리는 자리입니다. 제품마다 실제 소재·기능·용도가 적혀 있으면 "맥세이프 카드지갑 제작" 같은 구체적 검색어로 유입이 생깁니다. 지금은 70개 제품이 사진과 품목명만 있어 검색엔진이 서로 구분할 근거가 약합니다.

**받아야 할 것** 제품별로 이 정도면 충분합니다.
- 소재 (예: 이탈리아 베지터블 소가죽)
- 주요 기능 (예: 카드 3매 수납, 맥세이프 자석 내장)
- 용도나 대상 (예: 기업 판촉물, 브랜드 리테일용)

**전부 다 안 와도 됩니다. 일부만 와도 그것부터 반영합니다.** 70개를 한 번에 기다릴 필요 없습니다.

**대안** 자료가 계속 안 오면 사진과 품목명을 보고 초안을 써서 대표 확인을 받는 방식도 가능합니다. 다만 소재처럼 사실 확인이 필요한 항목은 비워두고 갑니다 — 없는 사실을 지어낼 수는 없으니까요.

**착수 조건** 자료가 오면 즉시. 부분 수령도 착수 사유입니다.

## 준비되면 바로 — 재료만 있으면 됨

### 📱 PWA — 휴대폰 홈 화면 아이콘

**무엇** 홈페이지를 앱처럼 설치 가능하게 만듭니다. 홈 화면 아이콘을 누르면 주소창 없이 전체화면으로 열립니다.

**왜** 업체 대표가 휴대폰에서 매번 검색해서 들어가는 불편을 없앱니다. 고객에게도 같은 효과.

**막고 있는 것** 정사각형 로고 원본, **512×512px 이상**. 현재 `public/images/logo_symbol.png`(3.7KB)와 `CI.png`(15KB)는 아이콘으로 쓰기엔 작아서 흐리게 나옵니다.

**작업량** 로고만 있으면 반나절.

**상품화 가능** 다른 고객사에 "홈페이지를 앱처럼 만들어 드립니다"로 팔 수 있습니다. 설명이 쉽고 결과가 눈에 보입니다.

### 🖼 언어별 OG 이미지

**현재 상태** SNS나 카카오톡에 링크를 공유할 때 나오는 이미지가 `thumbnail_ko.jpg` 하나로 4개 언어 공용입니다. 한국어 이미지가 영어·일본어·중국어 공유에도 그대로 나갑니다.

**막고 있는 것** 언어별 썸네일 이미지 4장. 같은 디자인에 문구만 각 언어로 바꾸면 됩니다.

**작업량** 이미지만 있으면 30분.

## 별도로 다뤄야 하는 것

### 📦 npm 취약점 6건 (high)

2026-08-27 `npm install` 실행 시 보고됨. 아직 내용을 확인하지 않았습니다.

⚠️ **`npm audit fix --force` 를 함부로 돌리지 마세요.** 의존성 버전을 강제로 올려 사이트가 깨질 수 있습니다. 먼저 `npm audit` 으로 무엇이 문제인지 보고, 빌드 도구에만 영향을 주는 것인지 실제 배포되는 코드에 영향을 주는 것인지 구분해야 합니다. 프론트엔드 프로젝트에서는 빌드 도구 쪽 경고가 대부분이고 실제 위험은 낮은 경우가 많습니다.

### 🗑 `sharp` 의존성 정리 여부

`package.json` 의 `sharp: ^0.35.3` 은 삭제된 `optimize.js` 를 위해 설치된 것입니다. Next.js 16 이 자체적으로 `sharp: ^0.34.5` 를 `optionalDependencies` 로 갖고 있음을 확인했습니다(`node_modules/next/package.json`).

다만 지웠을 때 문제가 생기면 **빌드 로그가 아니라 배포된 사이트의 이미지가 안 나오는 형태**로 나타납니다. 확인이 늦고 되돌리기 번거로운 실패라 죽은 코드 정리 커밋에 섞지 않았습니다. 다룰 때는 단독 커밋으로 하고, 배포 후 이미지가 정상 표시되는지 눈으로 확인하세요.

### 📄 `implementation_plan.md` 처리

저장소 루트의 6KB 문서. 내용을 아직 확인하지 않았습니다. 낡았다면 관리지침서로 흡수하거나 삭제.
