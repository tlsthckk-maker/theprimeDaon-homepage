## 대기 중 — 외부에서 자료가 와야 함

### ⏳ 쇼룸 제품 설명 75개

**현재 상태** 사전 파일(`src/i18n/locales/*.json`)의 `showroom.products` 75개 항목 설명이 전부 임시 문구입니다.

```
"[임시 특징 설명] 프리미엄 가죽 소재와 실용적인 카드 수납 기능이 돋보이는 모델입니다."
"[임시 특징 설명] 섬세한 텍스처와 메탈 링 디테일로 사용자의 편의성을 극대화한 제품입니다."
```

**라이브에 그대로 나가고 있습니다.** 제품 상세를 열면 고객이 이 문구를 봅니다.

**막고 있는 것** 업체 대표에게 제품 설명 자료를 요청해 둔 상태 (2026년 6월경 요청, 약 2개월 경과). 대표가 바빠서 지연 중.

**왜 중요한가** 쇼룸은 롱테일 검색이 가장 잘 걸리는 자리입니다. 제품마다 실제 소재·기능·용도가 적혀 있으면 "맥세이프 카드지갑 제작" 같은 구체적 검색어로 유입이 생깁니다. 지금은 75개가 전부 같은 종류의 빈 문장이라 검색엔진이 중복으로 판단합니다. 그리고 무엇보다 **고객이 보는 화면입니다.**

**받아야 할 것** 제품별로 이 정도면 충분합니다.
- 소재 (예: 이탈리아 베지터블 소가죽)
- 주요 기능 (예: 카드 3매 수납, 맥세이프 자석 내장)
- 용도나 대상 (예: 기업 판촉물, 브랜드 리테일용)

전부 다 안 와도 됩니다. **일부만 와도 그것부터 반영합니다.** 75개를 한 번에 기다릴 필요 없습니다.

**대안 (자료가 계속 안 올 경우)** 사진과 제품명만 보고 제가 초안을 써서 대표 확인을 받는 방식도 가능합니다. 빈 문장보다는 낫습니다. 다만 소재처럼 사실 확인이 필요한 항목은 비워두고 갑니다 — 없는 사실을 지어내면 안 되니까요.

**착수 조건** 자료가 오면 즉시. 부분 수령도 착수 사유입니다.

## 준비되면 바로 — 재료만 있으면 됨

### 📱 PWA — 휴대폰 홈 화면 아이콘

**무엇** 홈페이지를 앱처럼 설치 가능하게 만듭니다. 홈 화면 아이콘을 누르면 주소창 없이 전체화면으로 열립니다.

**왜** 업체 대표가 휴대폰에서 매번 검색해서 들어가는 불편을 없앱니다. 고객에게도 같은 효과.

**막고 있는 것** 정사각형 로고 원본, **512×512px 이상**. 현재 `public/images/logo_symbol.png`(3.7KB)와 `CI.png`(15KB)는 아이콘으로 쓰기엔 작아서 흐리게 나옵니다.

**작업량** 로고만 있으면 반나절.

**상품화 가능** 다른 고객사에 "홈페이지를 앱처럼 만들어 드립니다"로 팔 수 있습니다. 설명이 쉽고 결과가 눈에 보입니다.

### 🖼 언어별 OG 이미지

**현재 상태** SNS나 카카오톡에 링크를 공유할 때 나오는 이미지가 `thumbnail_ko.jpg` 하나로 4개 언어 공용입니다. 한국어 이미지가 영어·일본어·중국어 공유에도 그대로 나갑니다.

**막고 있는 것** 언어별 썸네일 이미지 4장. 같은 디자인에 문구만 각 언어로 바꾸면 됩니다.

**작업량** 이미지만 있으면 30분.

## 확인만 하면 되는 것

### 🔍 네이버 서치어드바이저 등록 여부

**국내 B2B는 구글보다 네이버가 더 중요합니다.** 등록됐는지 확인이 안 된 상태입니다.

- `searchadvisor.naver.com` → 사이트 등록 → 소유확인 → 사이트맵 제출 + 웹페이지 수집 요청
- 사이트맵 주소: `https://www.primedaon.com/sitemap.xml`

### 📍 네이버 스마트플레이스 등록

사업장 주소(서울 중랑구 봉우재로 108 3층)가 있으므로 등록 대상입니다. 회사명으로 검색했을 때 지도와 회사 정보가 뜨는 것과 안 뜨는 것은 신뢰도 차이가 큽니다.

### 🔀 apex → www 301 리다이렉트

`primedaon.com`(www 없이)이 301 없이 200으로 응답합니다. canonical이 있어 색인 통합은 되지만 301이 정석입니다. Vercel 도메인 설정에서 처리.
